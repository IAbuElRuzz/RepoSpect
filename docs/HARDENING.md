# Security hardening

- Local scans use data reads and Go parsers only. They do not launch scanners, interpreters, Git, package managers or MCP servers.
- File access is confined with os.Root, regular-file and same-file checks. Symlinks and special files are skipped. Walk and read errors reduce coverage rather than produce clean results.
- Traversal is capped at 20,000 entries (including directories), with byte, depth and graph limits. Only the first lexical match per rule/file is retained. Go regexes use RE2 rather than backtracking expressions.
- Remote acquisition accepts anonymous HTTPS GitHub owner/repository URLs only. Redirects, alternate hosts, URL credentials, query strings and fragments are rejected. Compressed and expanded sizes are capped. ZIP extraction rejects path traversal, duplicate paths, symlinks and special files. Files are created exclusively with private permissions in a fresh temporary directory and deleted after scanning.
- Revision comparison invokes the installed Git binary with argument arrays, an environment allowlist, disabled fsmonitor/hooks, no credential prompting, no global/system configuration, and no checkout. Revisions resolve to validated commit hashes before archive creation. Output is bounded, commands have context deadlines, and tar extraction rejects symlinks and special files. Git itself still parses repository configuration and object data; keep Git updated.
- No source excerpts are printed. Secret detections use generic descriptions. Terminal controls and bidi formatting characters are replaced in human-readable paths. JSON preserves escaped evidence paths and graphs use opaque node IDs.
- OSV is opt-in and limited to 1,000 unique exact package versions per request. Requests have deadlines, redirects are forbidden, responses have size bounds, IDs and result counts are validated, and pagination causes an explicit failure. Unresolved version ranges are not treated as checked.
- Configuration is explicitly supplied by the user; no repository-owned configuration is automatically loaded. Suppressions require reasons. AI is not implemented and receives no data.

These limits are not an OS sandbox or a hard memory/CPU quota. Runtime allocations can exceed input size, cancellation is cooperative between analysis operations, and Git archive generation is bounded by captured output rather than OS process memory. Analyze actively mutating inputs in an immutable snapshot. Remote fetching and OSV require HTTPS trust and may disclose repository identity or dependency names respectively. Read LIMITATIONS.md before treating results as a gate.
