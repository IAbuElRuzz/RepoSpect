# README visual assets

- `repospect-hero.png`: original RepoSpect hero artwork generated with the built-in image-generation tool. The exact prompt is preserved in `hero-prompt.txt`. This is brand artwork, not a screenshot or a claim about scan results. The generated image was copied into this repository; README rendering does not depend on an external image-generation URL.
- `fixture-trace.svg`: a project-authored vector illustration of selected actual output from `repospect scan testdata/suspicious --format json`. Three files and seven findings were observed when created. Descriptions are shortened to fit; inferred static references are labeled. This is a readable summary, not a pixel capture of a terminal.

Both assets are distributed under the project's Apache-2.0 license. Badge images in the README come from shields.io and do not claim a passing CI run, published release, download count or security certification.
