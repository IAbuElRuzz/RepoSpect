# Security policy

Do not include real credentials, functional malware or private repositories in public reports. For sensitive reports, contact the repository maintainers through a private security advisory if available. No monitored security address is established yet; do not assume public issues are private.

Report scanner code execution, path escapes, secret disclosure, denial of service, unsafe archive handling and misleading coverage as security concerns. Include a minimal inert reproducer, Go version, platform, expected behavior and actual output. This pre-release tool has no support SLA. Follow docs/THREAT_MODEL.md and docs/LIMITATIONS.md when interpreting results.
